# WanderLux — Travel Agency Website

A responsive, multi-page website for a fictional boutique travel agency, built from scratch with vanilla HTML, CSS and JavaScript.

## Pages & Features
- **Home** — hero landing page with featured destinations
- **About** — company story and team section
- **Services** — bespoke journeys, luxury getaways and guided tours
- **Appointment** — booking request form for client consultations
- **Contact** — enquiry form with validation
- **Trip Calculator** — interactive JavaScript tool that estimates trip costs based on destination and package options

## Tech
- Semantic HTML5, custom CSS (responsive layout, mobile nav toggle)
- Vanilla JavaScript: form validation, calculator logic, DOM interaction

## Run it
Open `index.html` in any browser — no build step needed.
